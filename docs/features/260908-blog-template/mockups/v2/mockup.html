论作为方法的提示词

把一句话交给模型，换回一篇文章——这件事被描述成魔法的次数太多了，被描述成劳动的次数太少了。1本文决定从自己开刀：这篇文章的起点不是灵感，而是一条四十九个字的指令，和一次自动化的三步生成。

1 「魔法」叙事的批判，见本站《上下文窗口的形而上学》。

提示词常被比作咒语，暗示念对了音节就能召唤结果。但咒语的本质是重复——错一个音就失效；提示词的本质是委托——你描述意图，把执行交给一个你并不真正理解的系统。这更像甲方给乙方写需求文档，而不是巫师召唤精灵。区别在于：乙方会跟你开会，模型不会。

委托关系里真正的技艺，不在措辞，而在判断：哪些思辨可以外包，哪些不可以。可以外包的是展开：论证、铺陈、例证、把一个念头拉长成三千字。2不可以外包的是立场：一句结论为什么值得说出口，只有那个愿意为它署名的人知道。

2 划线为本站固定语法：信号黄即「重点句」，通常每篇不超过两处。

所以提示词是一种方法：它强迫你在写作之前完成思辨。传统的写作把想清楚和写出来混在一起，因此拖延；提示词把两者拆开，你只剩下想清楚这一件事可做。

写作的障碍从来不是打字的速度，而是敢于承认自己想说什么。提示词只是把这份承认，提前到了打字之前。

当然，这一切有一个不舒服的推论：如果展开可以外包，那么被外包的部分就不构成作者性。署名者必须接受——这篇文章里真正属于他的，可能只有划了荧光的那一句话，和文末那行遥测数据。这不是谦辞，是账目。

剩下的部分，是模型的。它写得比我快，比我耐心，偶尔比我深刻。署名者做的事情只有三件：出题、验收、发布。你正在读的这篇文章，就是这套流程的一次运转。它的完整生成记录在页面底部，供任何人下载核验。
