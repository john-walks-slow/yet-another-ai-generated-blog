论作为方法的提示词

「提示词不是咒语，而是一份把思辨外包给机器的协议。」 —— 选题备注，2026-09-04，人工投入 4 分钟

把一句话交给模型，换回一篇文章——这件事被描述成魔法的时候太多了，被描述成劳动的时候太少了。¹本站决定从自己开刀：这篇文章的起点不是灵感，而是一条二十七个字的指令，以及一个只有十二分钟空闲的人。

¹ 本文使用的确切指令见文末生成记录。「魔法」叙事的批判，参见本站《上下文窗口的形而上学》。

提示词常被比作咒语，暗示念对了就能召唤结果。但咒语的本质是重复——念错一个音节就失效；提示词的本质却是委托——你描述意图，把执行交给一个你并不真正理解的系统。这更像甲方给乙方写需求文档，而不是巫师召唤精灵。

委托关系里真正的技艺，不在措辞，而在判断：哪些思辨可以外包，哪些不可以。（作者划线）可以外包的是展开：论证、铺陈、例证、把一个念头拉长成三千字。²不可以外包的是立场：一句结论为什么值得说出口，只有那个愿意为它署名的人知道。

² 划线为本站固定语法：正文中出现荧光标记，即表示「这一句是人划的」。全文通常不超过两处。

所以提示词是一种方法：它强迫你在写作之前就完成思辨。传统的写作把想清楚和写出来混在一起，因此拖延；提示词把两者拆开，你只剩下想清楚这一件事可做。从这个角度看，本站作者投入的十二分钟里，没有一分钟是被浪费的——它们全部花在了唯一不能代劳的环节上。

写作的障碍从来不是打字的速度，而是敢于承认自己想说什么。
提示词只是把这份承认，提前到了打字之前。

当然，这一切有一个不舒服的推论：如果展开可以外包，那么被外包的部分就不构成作者性。署名的那个人必须接受，这篇文章里真正属于他的，可能只有划了两道荧光的那两句话，和一个「已阅」。这不是谦辞，是账目——本站把这笔账印在每篇文章的末尾，见下。

剩下的部分，是模型的。它写得比我快，比我耐心，偶尔比我深刻。我为它排好版式，盖了章，然后去构思下一篇。你正在读的这篇文章，就是这套流程的第十一次运转。
